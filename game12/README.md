#### Астрометрическая редукция для серии fits-кадров с изображением астероида (NEA)

Основа кода - традиционный конвейер обработки, основанный на применении моделей астрометрической редукции от линейной до произвольного порядка. 

Рефакторинг и визуализация выполнены с помощью Claude Code

Реализованы последовательные сценарии обработки кадра:

1. nea_frame_analysis.ipynb - редукция по всему кадру, PSF - профиль Гаусса. Параметры A,B,C профиля калибруются по звездам с высоким SNR и применяются к изображениям всех объектов, включая изображение астероида.
2. nea_frame_analysis_control.ipynb - редукция по всему кадру, PSF - профиль Гаусса. Параметры A,B,C профиля калибруются по звездам с высоким SNR и применяются к изображениям всех объектов, включая изображение астероида. Отличие от 1. в том, что первые 5 звезд по расстоянию от изображения NEA - контрольные. То есть они "анализируются" в "режиме астероида". Тем самым "О-С" для контрольных звезд могут показать наличие систематических ошибок проекции. Опорные звезды тоже выбраны не по всему кадру, а взяты следующие 20 по расстоянию от изображения астероида. Используется линейная модель астрометрической редукции из соображения, что в небольшом рабочем поле значимы только параметры линейной модели. 
3. nea_frame_analysis_psf.ipynb - Это "клон" решения 2., но с существенным различием: теперь PSF берется по одной из звезд кадра с "хорошим SNR". То есть звезда не передержана и не слишком слабая. Выполняется "подгонка" этой "PSF" под изображения путем вариации координат центра и отношения потоков.

Все скрипты сохраняют результат своей работы в dataframe и csv-файл. В дальнейшем он может использоваться для решения разных задач, в том числе орбитальных.
